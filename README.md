# Lens Studio

Lens Studio is a modern portfolio web app for videographers to showcase and manage video projects. Built using HTML, CSS, and Vanilla JavaScript with DOM manipulation and localStorage.

## Features
- Project gallery (dynamic rendering)
- Add new projects via form
- Save projects using localStorage
- Smooth scrolling navigation
- Hover interactions and minimal animations
- Responsive design (mobile/tablet/desktop)
- Sticky header with scroll effect

## Tech Used
HTML, CSS, JavaScript

## How to run
Open index.html in your browser or use Live Server in VS Code.
